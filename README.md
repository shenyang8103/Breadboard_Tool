# ProtoboardMaster · 洞洞板大师

**[简体中文](README.md) | [English](README.en.md)**

**[在线使用](https://shenyang8103.github.io/ProtoboardMaster/) · [GitHub 仓库](https://github.com/shenyang8103/ProtoboardMaster) · [下载 HTML](https://github.com/shenyang8103/ProtoboardMaster/blob/main/ProtoboardMaster.html)**

面向电子爱好者的面包板与洞洞板布局工具。在浏览器中摆放元件、连接飞线、规划背面焊锡，并查看实际导通关系。一个 HTML 文件即可离线使用，无须安装或联网。

用于搭建和焊接前的布局对照，不提供电路仿真或 PCB 设计。当前操作界面为中文。

## 快速开始

1. 下载或保留完整的 [ProtoboardMaster.html](ProtoboardMaster.html)，在电脑浏览器中打开。
2. 点击工作台标题后的灰色提示，在面包板和洞洞板之间切换。
3. 载入示例体验，或新建空板，选择工具后点击孔位开始放置。
4. 使用“保存项目”备份工程；需要焊接或分享时导出图片。

同时只运行一个编辑器。未保存时切换会询问“保存后切换”“放弃修改并切换”或“取消”；保存失败或取消会留在当前工具。放弃会清除该工具当前本地草稿，不删除已保存的项目文件。切换后旧工具的撤销和系统保存目标释放，重新进入可恢复未放弃的草稿。

## 主要功能

| 面包板 | 洞洞板 |
| --- | --- |
| 1～8 块板子、板序拖动、跨板飞线 | 可调行列、可拖动尺寸预览框与受影响对象清单 |
| 可调主区排数、电源轨与分段导通 | 正反面切换、设计镜像开关、另一面淡显 |
| 电阻、电容、二极管、三极管、DIP 芯片、引出线 | 固定元件、DIP 芯片、自定义元件与引脚微调 |
| 飞线七色、元件复制、单脚重接、多选移动 | 正面红色飞线、背面蓝色飞线、灰色焊锡走线 |
| 孔位导通高亮、占孔检查与冲突处理 | 悬停完整网络高亮、焊锡直线段拖动及自动补接 |
| 完整布局 PNG、逐板 PNG/ZIP | 正反面 PNG/ZIP、JSON/CSV 连接清单 |

两种工具均支持连续放置、属性修改、直接抓取、单步撤销、保存/打开和本地草稿。芯片和其他元件内部不会被当成自动导通的导线；同名引出标签也不自动连接。

## 鼠标与快捷键

| 操作 | 效果 |
| --- | --- |
| 左键点击 | 选孔、选对象或放置 |
| 左拖已选对象 | 移动；两脚元件/飞线的端点圆环可用于单脚调整 |
| 空白处左拖 / Ctrl 点选 | 框选 / 增减选择；洞洞板 Ctrl 框选可追加 |
| 短按右键 | 两点绘制已选起点时先清起点、保留工具与参数；没有起点时退出工具；选择状态清选 |
| 右键拖动 / 滚轮 | 平移 / 缩放，右拖保留绘制起点 |
| Esc | 退出当前编辑或取消选择 |
| M / C / Del | 移动 / 复制单个对象 / 删除所选对象 |
| 空格 | 支持换向的元件在放置、移动、复制时换向；二极管交换极性 |
| Ctrl+Z / Ctrl+S | 撤销一步 / 保存项目 |
| F（洞洞板） | 选择查看模式下切换正反面 |

输入框、下拉菜单和弹窗内按各自输入规则处理快捷键。撤销只有一步；未完成预览和右键清起点不消耗已完成编辑的撤销。

## 洞洞板连接规则

- 元件脚与飞线端点是实体，同一孔只能插一个，正反面共同检查占孔。
- 焊锡只在背面，不占插孔；已有焊锡的空孔可以插脚或接飞线，也可以继续分支走线。
- 焊锡经过同一焊盘就实际导通，重复边合并；飞线仅两端导通，线身交叉不连接。
- 背面设计默认不镜像，背面图片导出默认镜像，方便对照焊接；两者设置独立。

## 保存与兼容性

- 面包板文件为 `.breadboard.json`，支持旧单板 v1 和多板 v2；洞洞板为 `.perfboard.json`。请在对应工具打开，两种布局不自动转换。
- 支持系统保存窗口时可选择位置，后续保存写回本页选定的文件；否则使用浏览器下载。若在浏览器中取消下载，请重新保存。
- 本地草稿仅用于恢复，不替代文件备份。不同浏览器、地址、端口或离线文件路径的草稿可能不互通。首次从旧文件名切到 `ProtoboardMaster.html` 时，请通过已保存的项目文件迁移，不保证旧草稿自动迁移。
- 草稿不保存临时预览、选择、撤销历史和系统文件句柄。不要把浏览器缓存作为唯一存档。
- 图片用于布局对照，不保证打印物理尺寸；网表是实际导通检查清单，不是仿真文件。

首版功能已完成；常用浏览器直接离线打开、系统保存窗口和实际焊接对照仍需试用验收。旧的 Breadboard_Tool 仓库已沿用并更名为 ProtoboardMaster。旧项目网址不会自动跳转；本地草稿也不保证随地址迁移，请先保存项目文件再在新网址打开。

## GitHub Pages

网页从 main 分支根目录发布，无需安装依赖或构建。index.html 与 ProtoboardMaster.html 是同一份完整应用。离线使用时，在 GitHub 文件页面通过原始文件下载按钮下载 ProtoboardMaster.html 即可。
