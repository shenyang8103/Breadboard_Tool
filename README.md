# 面包板布局与连线工具

在电脑浏览器中辅助面包板布局和实际插接，支持多板排列、元件放置、连线及网络高亮，不做电路仿真。

**[在线使用 / Open online](https://shenyang8103.github.io/Breadboard_Tool/)** · [GitHub 仓库](https://github.com/shenyang8103/Breadboard_Tool)

## 使用方法

- **离线使用**：下载本仓库的 `index.html`，用电脑浏览器打开即可，无需安装，也不需要其他文件。
- **在线使用**：仓库启用 GitHub Pages 后，通过 Pages 地址打开。在线和离线版使用同一份文件。
- 电路在浏览器本地编辑，不上传到服务器；不同用户的编辑互不影响，不提供协同编辑。

## 主要功能

- 横置/竖置面包板，30～70 排可选，最多 8 块板，支持插入、删除、拖动换序及板型裁切预览。
- 导线、电阻、电容、二极管、三极管、DIP 芯片及引出线；连续放置、七色连线、引脚命名和支持换向的元件空格反转。
- 网络高亮、占孔检查及同网络短接警告；支持单选、多选、整体移动、复制、删除和一步撤销。
- 保存和打开 `.breadboard.json` 项目，包含板型、元件与连线；本地草稿辅助恢复。
- 导出完整布局 PNG，或按板导出带相邻板号、跨板连接说明的 PNG，并打包 ZIP。

## 常用操作

| 操作 | 方法 |
| --- | --- |
| 放置元件或导线 | 选择工具后点击孔位，完成一项后继续放置同类型 |
| 移动视图 | 按住鼠标右键拖动 |
| 选择多个对象 | 左键框选，或按住 Ctrl 点选 |
| 移动已选对象 | 按住已选对象左键拖动，或按 M |
| 复制单个对象 | 选中后按 C |
| 换向 | 选中或放置二极管、三极管、芯片、引出线时按空格 |
| 删除 | 选中后按 Delete；整板删除会先确认 |
| 撤销 | Ctrl+Z，支持一步撤销 |
| 结束放置/取消选择 | Esc 或短按鼠标右键 |

修改名称时按 Enter 或离开输入框应用；颜色和下拉选项选定即生效。芯片自动跨中央槽定位，放置后封装不可修改。

## 保存电路

使用顶部“保存项目”保存可继续编辑的 `.breadboard.json` 文件，右侧下拉可选“另存为”。支持系统文件选择器的浏览器可选择路径并在本页再次保存时写回；其他情况下使用浏览器下载，位置由浏览器下载设置决定。刷新页面后需重新选择写入目标。

本地草稿属于当前浏览器和入口地址，不会自动写回项目文件。清理浏览器数据、换浏览器或换网址可能使草稿不可用；需要保留电路时请保存项目。图片只用于查看和打印，不能代替项目文件。

## 部署到 GitHub Pages

此仓库仅包含 `index.html` 和 `README.md`，无需安装依赖或执行构建。

1. 将本仓库推送到 GitHub 的公开仓库。
2. 在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**。
3. 发布分支选择 **main**，目录选择 **/(root)**，保存。
4. 部署完成后，在 Pages 设置中获取网站地址。使用 GitHub 提供的默认地址即可，无需购买域名。

GitHub Free 支持公开仓库的 Pages；部署方式见 [GitHub 官方文档](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)。网页及其前端代码可被访问者下载。
